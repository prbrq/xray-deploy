# AGENTS.md

## Назначение проекта

`xray-deploy` — одноразовый дистрибутив минимального Xray REALITY-сервера. После успешного `bootstrap.sh` целевой VPS намеренно отделяется от шаблонного репозитория: сохраняется `DEPLOYED_FROM`, а каталог `.git` удаляется.

## Принцип реализации

- Не используйте временные обходы. Устраняйте первопричину и реализуйте решение правильно, безопасно и с минимально необходимыми привилегиями с самого начала.
- Не ослабляйте права доступа, модель безопасности или изоляцию ради прохождения проверки; если это необходимо, сначала согласуйте изменение с пользователем.

## Безопасность и секреты

- Никогда не добавляйте в Git `.env`, `config.json`, `DEPLOYED_FROM`, VLESS URI, UUID, REALITY private/public keys, short ID или данные конкретного VPS.
- Не выводите секреты в логи, README, примеры команд и сообщения об ошибках.
- `.env` и `config.json` должны оставаться с правами `0600`.
- Не заменяйте закреплённый digest образа Xray без явного запроса и согласованного обновления документации/конфигурации.

## Поведение deployment-скриптов

- Не запускайте `./bootstrap.sh` без явного запроса пользователя: он обращается к сети и Docker, создаёт credentials и после успешного deploy удаляет `.git`.
- REALITY target не выбирается автоматически; сохраняйте интерактивный выбор и TLS-проверку target/SNI.
- Повторный bootstrap должен сохранять уже существующие credentials из `.env`.
- Любые переменные, добавленные в `.env.example`, должны быть синхронизированы с `bootstrap.sh`, `deploy.sh` и при необходимости `profile.sh`/`config.json.template`.
- Не меняйте VLESS + RAW/TCP + `xtls-rprx-vision` + REALITY и порт `443/tcp` без явного запроса.

## Проверки изменений

- После изменения shell-скриптов выполняйте: `bash -n bootstrap.sh deploy.sh profile.sh`.
- Для изменений шаблона/Compose не запускайте Docker deployment без явного запроса: для полной проверки нужны Docker и доступная VPS-сеть.
- Поддерживайте README на русском и актуализируйте его, если меняется поведение bootstrap, deploy или формат клиентского URI.
